# Анализ имеющихся решений
## Baseline
Ниже приведены системы и информационные потоки в базовой архитектуре.

Таблица - список систем
| ИС | Функции |
| --- | --- |
| ИС «Алмазы» | Планирование работ, присвоение идентификаторов и подготовка ведомостей |
| ИС «Логистика» | Перевозка алмазов |
| ИС «Бухгалтерия» | Актирование и оплата услуг компаний-перевозчиков, ведение контрактов |
| ИС «Аукцион» | Проведение аукциона |


Таблица - список информационных потоков

| Субъект | Объект | Данные | Способ передачи | Интерфейс |
| --- | --- | --- | --- | --- |
| Клиент | Аукцион | Заявка на участие | Сотрудник -> ИС "Аукцион" | Физическое взаимодействие -> UI |
| Клиент | Модуль торгов | Ставка по лоту | Сотрудник -> ИС "Аукцион" | Физическое взаимодействие -> UI |
| Аукцион | Клиент | Счёт на оплату | ИС "Бухгалтерия" | Физический расчёт | 
| Клиент | Аукцион | Оплата по счёту | (Ручной -> Сотрудник ИЛИ терминал) -> ИС "Бухгалтерия" | [Физический расчёт -> Сотрудник] -> SOAP | 
| Аукцион | Клиент | Результаты торгов | ИС "Аукцион" | UI | 
| Отдел закупок | Группа перевозок | Заказ на доставку | ИС "Логистика" | UI |
| Группа перевозок | Финансовый отдел | Счёт за доставку | "Логистика" -> ИС "Бухгалтерия" | UI -> SOAP |


## MVP
Применение в минимально-достаточной (транзитивной) архитектуре существующих решений:
| ИС | Новые Функции | Статус ИС |
| --- | --- | --- |
| ИС «Алмазы» | - | Без доработок ✔ |
| ИС «Логистика» | - | Без доработок ✔ |
| ИС «Бухгалтерия» | - | Без доработок ✔ |
| ИС «Аукцион» | - | Без доработок ✔ |

>>Интеграции в минимально-достаточной (транзитивной) архитектуре реализуются через ручное управления данными, по средством офисных инструментов (Excel)

| Субъект | Объект | Данные | Способ взаимодействия | Статус интеграции | 
| --- | --- | --- | --- | --- |
| ИС «Алмазы» | ИС «Логистика» | Накладные по алмазам | REST API | Существующая ✔ |
| ИС «Логистика» | ИС «Бухгалтерия»  | Счета по перевозкам | SOAP | Существующая ✔ |
| ИС «Лаборатория» | ИС «Аукцион»  | Описание алмазов | Ручной (UI) | Новая ✳ |
| ИС «Лаборатория» | ИС «Бухгалтерия»  | Описание алмазов | Ручной (UI) | Новая ✳ |


Ключевые решения минимально-достаточной архитектуры:
* Аренда облачных SaaS продуктов для отслеживания онлайн торгов и формирование счётов на оплату;
* Ручное формриование списка онлайн участников;
* Ручное обновление статуса онлайн торгов;
* Ручное выставление счёта клиенту по результатам торгов;
* Ручная регистрация и организация доставки лота клиенту.



## Target
Применение в целевой архитектуре существующих решений:
* ИС «Алмазы» - функционал не меняется;
* ИС «Логистика» - подключить новую точку отрузки товара;
* ИС «Бухгалтерия» - подключить облачный SaaS сервис для управления счетами онлайн оплаты лота.

| ИС | Новые Функции | 
| --- | --- |
| ИС «Алмазы» | Без доработок ✔ |
| ИС «Логистика» | Подключение новой точку отрузки товара | Доработка ⚠ |
| ИС «Бухгалтерия» | Управление счетами онлайн оплаты лота через облачным SaaS сервис | Доработка ⚠ |
| ИС «Лаборатория» | Оцифровка алмазаов и ведение онлайн витрины | Разработка ✳ |
