## MVP
Применение в минимально-достаточной (транзитивной) архитектуре существующих решений:
| ИС | Обновление |
| --- | --- |
| ИС «Алмазы» | - |
| ИС «Логистика» | - |
| ИС «Бухгалтерия» | - |

Создание новых интеграций в минимально-достаточной (транзитивной) архитектуре не требуется.

Ключевые решения минимально-достаточной архитектуры:
* Аренда облачных SaaS продуктов для отслеживания онлайн торгов и формирование счётов на оплату;
* Ручное формриование списка онлайн участников;
* Ручное обновление статуса онлайн торгов;
* Ручное выставление счёта клиенту по результатам торгов;
* Ручная регистрация и организация доставки лота клиенту.



## Target
Применение в целевой архитектуре существующих решений:
* ИС «Алмазы» - функционал не меняется;
* ИС «Логистика» - подключить новую точку отрузки товара;
* ИС «Бухгалтерия» - подключить облачный SaaS сервис для управления счетами онлайн оплаты лота.

| ИС | Обновление |
| --- | --- |
| ИС «Алмазы» | - |
| ИС «Логистика» | Подключение новой точку отрузки товара |
| ИС «Бухгалтерия» | Управление счетами онлайн оплаты лота через облачным SaaS сервис |

Применение в целевой архитектуре новых решений:
| ИС | Функционал |
| --- | --- |
| ИС «Лаборатория» | Оцифровка алмазаов и ведение онлайн витрины |

Применение в целевой архитектуре новых интеграции:
* ИС «Лаборатория» -> ИС «Аукцион» - Передача описания алмазов для проведение торгов
* ИС «Лаборатория» -> ИС «Бухгалтерия» - Актирование и оплата услуг лаборатории.

Ключевые решения целевой архитектуры:
* Аренда облачных SaaS продуктов для отслеживания онлайн торгов и формирование счётов на оплату;
* Автоматическое формриование списка онлайн участников;
* Автоматическое обновление статуса онлайн торгов;
* Автоматическое выставление счёта клиенту по результатам торгов;
* Автоматическая регистрация и организация доставки лота клиенту по результатам торгов;
* Автоматизированная доставка алмазов на склады контрагента;
* Автоматизированное выставление счетов организации по резальтатам деятельности контрагентов.
